# Projeto de QA – Bootcamp

**Aplicação:** BugBank  
**Objetivo:** Validação funcional da aplicação  

## Atividades realizadas
- Elaboração do plano de testes  
- Criação e execução de casos de teste para cenários críticos (cadastro, login, transações)  
- Identificação e documentação de bugs com evidências e passos para reprodução  
- Aplicação de testes funcionais baseados em requisitos
